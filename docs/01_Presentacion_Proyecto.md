# Gargobarb - Documentación de Presentación

## 📄 Resumen General
Gargobarb es una plataforma **SaaS (Software as a Service)** de vanguardia diseñada específicamente para la industria de la barbería. No es solo un sistema de citas; es una herramienta de marketing y gestión integral que permite a los barberos tener su propia identidad en la web sin conocimientos técnicos.

## 🎯 Problema que resuelve
Actualmente, las barberías pequeñas y medianas dependen de:
- Agendas físicas o chats de WhatsApp desordenados.
- Falta de una vitrina profesional propia (dependencia de redes sociales).
- No tienen datos reales sobre sus visitas o rendimiento.

**Gargobarb** centraliza todo en una suite digital profesional.

## 👥 Público Objetivo
1. **Dueños de Barbería:** Necesitan control, estadísticas y visibilidad.
2. **Barberos Independientes:** Buscan profesionalizar su marca personal.
3. **Clientes:** Buscan una experiencia rápida y moderna para reservar servicios.

## 💡 Solución Propuesta
Un ecosistema que incluye:
- **Asistente (Wizard):** Para configurar un negocio en menos de 5 minutos.
- **Site Builder:** Un editor visual para personalizar la página web pública del local.
- **Panel Administrativo:** Para gestionar citas, servicios y estadísticas de ventas.

## 🛠 Tecnologías Utilizadas
- **Frontend:** React 18, Vite, Framer Motion, Lucide React, Axios.
- **Backend:** Node.js (Express), Sequelize (ORM).
- **Base de Datos:** MySQL.
- **Integraciones:** Google Maps API (Geolocalización).

## 🚀 Ventajas Competitivas
- **Estética "Premium":** Interfaz Dark Mode minimalista y moderna.
- **Velocidad:** Basado en Vite para tiempos de carga ultrarrápidos.
- **Autonomía:** El barbero puede cambiar su diseño web instantáneamente sin programar.
